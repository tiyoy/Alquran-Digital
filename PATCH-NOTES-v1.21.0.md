# Nurani v1.21.0 — Koleksi Ayat dan Folder Bookmark

## Perubahan

- Menambahkan halaman `/koleksi-ayat` dan menu navigasi **Koleksi**.
- Menambahkan pengelola folder dengan nama, deskripsi/catatan singkat, dan warna.
- Menambahkan ikon **Simpan ke koleksi** pada tiap kartu ayat dan tiap hasil pencarian.
- Mendukung memasukkan satu ayat ke beberapa koleksi, mengeluarkan ayat dari koleksi, serta menambahkan ayat dari bookmark umum.
- Menambahkan tindakan buka ayat, toggle bookmark umum, dan bagikan daftar referensi dengan tautan ayat individual.
- Menambahkan validasi dan ekspor/impor backup untuk `aq:verse-collections`.
- Memperbarui metadata, sitemap melalui konfigurasi route, daftar app shell, dan service worker ke `nurani-pwa-v34`.

## Batasan

Koleksi disimpan lokal di perangkat. Berbagi koleksi membagikan daftar referensi dan tautan ayat, bukan URL publik koleksi.
